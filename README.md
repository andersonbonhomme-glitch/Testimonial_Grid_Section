<h2 id="aperçu">Overview</h2>
<p><strong>The challenge</strong></p>
<p>Users must be able to :</p>
<ul>
  <li>Access the web page on a mobile such as Samsung S25/S25 Ultra and Iphone 17/17Pro, I have adapted the website for this kind of mobile size. And also, they can access it on a desktop with a minimum width of 1440px.</li>
  <li>See that the page is accessible to everyone by using HTML semantics and accessibility best practices and by creating states such as hover, active, and focus</li>
</ul>
